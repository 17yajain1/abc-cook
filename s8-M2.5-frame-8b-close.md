## 2. Code implementation (frame 8b) — `30bcece`

Confirmed the correct handoff copy first — an older draft (frame **7d**, contradicting
the amendments: cue-led task rows, an echo-suppression rule) sat in a different local
folder than the current one (frame **8b**); flagged the discrepancy and the owner pointed
at the right file once asked.

`apps/web/src/`, implemented in the handoff's stated order:

- **`index.css`** — `--stage-ground-alpha: 0.18`.
- **`lib/stageColor.ts`** — `stageGround(index)`, alpha-composited via `color-mix`
  against `transparent` so it composites correctly regardless of what's behind it.
- **`plan/StageCard.tsx`** — 22px filled badge, `text-paper` ordinal on the stage tint.
  Badge number and badge tint both now derive from `stage.index` — previously the
  ordinal came from filtered render position (`i + 1` in `PlanScreen`) while the tint
  came from the raw graph index, which is the exact M2 defect the doc names ("stage ①
  drawn in stage-1's tint"). Tinted ground wraps header + rows + the nested panel. The
  window host's row is restored to the inline task list instead of being replaced by
  its field. Collapsed stages hosting a window show "N free" / "~N min".
- **`plan/WaitWindowBlock.tsx`** — shrank the most: the subject line, doneness cue, and
  44px numeral are gone (that information is the host's own `TaskRow` now, one row up).
  The panel is inset inside the stage's own padding rather than full-bleed via negative
  margins. New `hostStageIndex` prop drives the panel's leading-edge colour (distinct
  from a borrowed task's own `homeStageIndex`). Tint bar on ranked tasks is now
  conditional on the window spanning more than one home stage.
- **`plan/PlanScreen.tsx`** — dropped the now-unneeded `position`/`isLast` props;
  `pb-28` → `pb-56` for CTA clearance (matching the studies' measured 220px); fixed two
  comments that had gone stale (the gutter no longer has anything bleeding across it).

**Tests** — owner's call: pure-function extraction (`stageOrdinal`, `freeMinForStage`,
`attentionLine`, `hasMultiHomeStage`), unit-tested directly against the real fixtures, no
new dependencies — matching `derive.test.ts`'s existing idiom rather than introducing

host/window invariant added to `derive.test.ts`. 30 tests green, `tsc -b` clean, `oxlint`
clean (two expected `only-export-components` warnings from colocating helpers with
components — an accepted tradeoff of that test strategy, non-fatal).
